# Portfolio site

Edit `index.html`: replace YOUR NAME and YOUR-EMAIL@example.com (search for both, they appear several times).

## Put it online with GitHub Pages
1. Create a public repository on GitHub, for example `portfolio`.
2. Upload everything in this folder (keep the folder structure).
3. Repository Settings > Pages > Source: "Deploy from a branch", Branch: `main`, folder `/ (root)`, Save.
4. After about a minute the site is at `https://YOUR-GITHUB-USERNAME.github.io/portfolio/`.
